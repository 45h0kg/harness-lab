# shelf

A small library for a shop: prices, carts and stock.

- `src/money.js` formats and rounds prices. Prices are stored as integer cents.
- `src/cart.js` builds carts and computes totals.
- `src/inventory.js` tracks stock per SKU.
- `src/config.js` holds shop settings. The default currency is USD.

Run the tests with `npm test`.
